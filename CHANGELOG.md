# Changelog

## 1.0.0 (2026-10-11)

First release.

- Fifteen bilingual modules, about 38 hours of study, from first principles to the expert report,
  each with a lesson, steps, common mistakes, a note on Kuwaiti law, references and a quiz.
- The Sanbouk practice case: a deterministic, fully synthetic incident with a disk image, browser
  history, a Windows shortcut, server and Windows logs, a packet capture, a custody log with a tampered
  archive copy, and twelve questions graded by hash.
- Six in-browser labs: fingerprints, file signatures, EXIF with the nearest Kuwaiti area, a hash chained
  custody log you can break, the case timeline in Kuwait time or UTC, and the case answer check.
- The `qassas` toolkit in Python with no dependencies: hashing and manifests, a hash chained custody log,
  signatures, carving, metadata, Arabic aware strings, browser history, LNK parsing, auth.log and Windows
  event analysis, pcap analysis with beaconing detection, timelines and bilingual reports.
- An MCP server with fourteen read only tools confined to one folder.
- A register of 35 laws, rulings and standards across Kuwait, the GCC and international bodies, researched
  and linked to sources on 11 October 2026.
- A catalogue of 34 open source DFIR tools with licenses read from each repository on 11 October 2026.
- An explainer video in Arabic and English with captions, and nineteen illustrated scenes.
